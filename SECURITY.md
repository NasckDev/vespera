# Segurança

O Véspera é um jogo single-player offline; o único dado local é o save em `user://save.json`.
Ainda assim, se você encontrar algo como execução de código por save malicioso, problema no
instalador ou no pipeline de release:

1. **Não abra issue pública.**
2. Use **[Report a vulnerability](https://github.com/NasckDev/vespera/security/advisories/new)** (aba *Security* do repositório).
3. Descreva o passo a passo para reproduzir e a versão afetada.

Respondemos assim que possível. Versões suportadas: só a última release.
