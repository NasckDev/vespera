# Ato V · Guardião Sineiro Mudo, uma tira por fase

**O que é:** o Guardião do **Ato V**, **Sineiro Mudo** (gárgula do tamanho do sino, sem boca), com uma tira por fase (CAMPANHA.md): fase 1 *FESTA* (`badalar`: anéis de choque; partes: 2 asas), fase 2 *CORDA* (`voar`, `mergulhar` com sombra no chão, `cordas` que descem do teto), fase 3 *CULPA* (silêncio total: só avisos visuais). A palavra em pedra de cada fase é texto do jogo, NÃO vai na arte. Escala ~3x o caçador.

Um prompt por imagem. Gere primeiro o `parado` de cada monstro e anexe-o nos pedidos seguintes do mesmo monstro. Todo golpe forte tem uma tira de `aviso` com brilho âmbar (o jogador lê o golpe pela cor).
