# Ato IV · Guardiã Velória, uma tira por fase

**O que é:** a Guardiã do **Ato IV**, **Velória** (colosso de cera, centenas de chamas), com uma tira por fase (CAMPANHA.md): fase 1 *Vigília* (`lancar`: atira velas que viram Velinhas; partes: 3 candelabros), fase 2 *Cera* (`derreter` + `ressurgir`: vira poça que anda e ressurge), fase 3 *Uma vela* (`apagar`: restam 5 velas; fala única "Qual delas é você?"). Escala ~3x o caçador.

Um prompt por imagem. Gere primeiro o `parado` de cada monstro e anexe-o nos pedidos seguintes do mesmo monstro. Todo golpe forte tem uma tira de `aviso` com brilho âmbar (o jogador lê o golpe pela cor).
